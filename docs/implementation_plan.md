## 1. Client Review Workbook

[`frontend/Angel_Fashion_Studio_Client_Review.xlsx`](file:///d:/angel/angel/frontend/Angel_Fashion_Studio_Client_Review.xlsx)
is generated by [`frontend/generate_client_excel.js`](file:///d:/angel/angel/frontend/generate_client_excel.js).

The workbook was **rewritten for a non-technical reader** (the store owner). It contains no
URLs, field names, or file paths. Product counts are read **live from the production database**
at generation time, so every "how many products show here" figure is real.

| Tab | Purpose |
|---|---|
| **1. Start Here** | What the file is, how to use it, and a snapshot of the shop (products, photos, stock, tag counts). |
| **2. Your Products** | Every uploaded product: price, where it sits in the menu, photo count, stock, tags, and any problem found. |
| **3. Menu Check** | Every clickable menu path with the number of products behind it, flagged `EMPTY` / `bare` / `Good`. |
| **4. Home Page** | Each home page section top-to-bottom in plain words, with where it links and how many products are there. |
| **5. Your Words** | About/Contact copy and the site-wide lines, for the client to correct. |
| **6. Policies** | Shipping, returns, privacy and terms in full. |
| **7. Things To Fix** | Ten plain-language issues with recommendations, plus an "already done" list. |

Regenerate with `node generate_client_excel.js` from `frontend/` (needs the backend `.env`).

## 2. Architecture

```
ADMIN PANEL      form dropdowns built from taxonomy.json
      │
      ▼
BACKEND          productModel.js derives its enums from taxonomy.json
(MongoDB)        → an invalid value cannot be saved
      │  GET /api/products
      ▼
STOREFRONT       1. Mega-menu rendered from taxonomy.json
                 2. Products page syncs filters to URL query params
                 3. filter_reducer matches case-insensitively
```

`frontend/src/utils/taxonomy.json` is the single source of truth for all four layers.

### Production data fix

`productType: "Indowestern"` (pre-rename spelling). It was invisible to the Indo Western

still sees the original message, since that genuinely is a filter problem.
